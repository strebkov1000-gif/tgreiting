# Images Folder

Upload your images here for the Ice Rating Bot Mini App.

## Loading Screen Background
- **File name:** `loading-bg.jpg` or `loading-bg.png`
- **Recommended size:** 1080x1920px (mobile portrait)
- **Format:** JPG or PNG
- **Usage:** Background image for the loading screen

## How to Upload

### Option 1: Using SCP (from your computer)
```bash
scp your-image.jpg root@130.49.160.207:/root/ice-rating-bot/frontend/public/images/loading-bg.jpg
```

### Option 2: Using wget (from URL)
```bash
cd /root/ice-rating-bot/frontend/public/images
wget -O loading-bg.jpg "YOUR_IMAGE_URL"
```

### Option 3: Direct file upload via IDE
Use your IDE's file upload feature to upload to this directory.

## Current Images
Run `ls -lh` in this directory to see uploaded images.
